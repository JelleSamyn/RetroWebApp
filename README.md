# Retro

Welcome to my retro games, a web-based platform hosting a collection of classic arcade-style games!

## 🎮 Play Online
You can play the games directly in your browser on our official site:
👉 **[game.jellesamyn.be](https://game.jellesamyn.be)**

## 🚀 Included Games
- **Space Blaster**: Navigate your ship and shoot down enemies in this fast-paced cosmic shooter!
- **Dungeon Quest**: Explore deep dungeons, battle monsters, and find hidden treasures!
- **Pixel Racer**: Start your engines and drift your way to victory in this retro-styled racing game!

## 🛠️ Development
This repository contains the source code for the Retro Web App and its included games. It is built using HTML, CSS, and Vanilla JavaScript to ensure smooth, lightweight performance directly in the browser.

### Running Locally
To run the project locally, simply serve the files using a local web server (e.g., using `Live Server` in VS Code, or Python's `http.server`).
